This post exists only as a template to copy. It is marked `draft: true`, so it
shows up locally but **never publishes**.

## How to use this template

1. Duplicate this file inside `src/content/blog/en/`.
2. Rename the file — the filename becomes the post's address.
3. Fill in the fields above and write the body here.
4. Change `draft: true` to `draft: false` when it is ready.

The `translationKey` must match the Spanish version. That is what lets the
language switcher take a reader to the same post rather than the blog index.
